# Resources CGS Hub (FiveM et RedM)

Resources officielles qui relient votre serveur de jeu à [CGS Hub](https://cgs-hub.com) :

- **votes** : récompense des joueurs qui votent pour votre serveur, en direct (webhook signé) ou au prochain sync ;
- **synchronisation** : état du serveur et fréquentation, consultables dans votre espace de gestion.

## Téléchargement

Prenez l'archive de votre jeu dans la [dernière version](https://github.com/CGS-Group/cgshub-resources/releases/latest) :

| Jeu | Archive | Frameworks |
|---|---|---|
| FiveM | `cgshub-fivem-vX.Y.Z.zip` | ESX, QBCore, Qbox, ox_core, standalone |
| RedM | `cgshub-redm-vX.Y.Z.zip` | VORP, RSG, standalone |

## Installation

Le guide complet se trouve dans la doc : [FiveM](https://cgs-hub.com/docs/api/plugin-fivem) · [RedM](https://cgs-hub.com/docs/api/plugin-redm).

Ce dépôt ne contient que les versions publiées. Pour toute question, utilisez le support CGS Hub.

# CGS Hub resources (FiveM and RedM)

Official resources linking your game server to [CGS Hub](https://cgs-hub.com): vote rewards (signed webhook or next sync) and server status and attendance sync. Download the archive for your game from the [latest release](https://github.com/CGS-Group/cgshub-resources/releases/latest), then follow the guide: [FiveM](https://cgs-hub.com/docs/api/plugin-fivem) · [RedM](https://cgs-hub.com/docs/api/plugin-redm).
